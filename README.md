# Ritika Sethi — academic website

Personal academic website for Ritika Sethi, hosted with GitHub Pages at
[sethiritika.github.io](https://sethiritika.github.io/).

The site is built with plain HTML, CSS, and JavaScript. It has no build step or
runtime dependencies.

## Preview locally

From the repository directory, run:

```bash
python3 -m http.server 8000
```

Then open [http://localhost:8000](http://localhost:8000/).

## Deployment

GitHub Pages can publish this repository directly from the `main` branch and
repository root. A GitHub Actions workflow is not required for this static site.

In the repository settings, choose **Pages → Deploy from a branch → main → /(root)**.
